# نمای کلی

`ns-didar` سامانهٔ درخواست با فرم‌های ازپیش‌تعریف‌شده است؛ form builder عمومی نیست. فرم‌ها از `Didar_Form_Registry` خوانده می‌شوند و هر ثبت یک `didar_submission` است. کاربر واردشده با `[didar_form type="…"]` ثبت و با `[didar_submissions]` سابقهٔ خود را می‌بیند.

همگام‌سازی Didar فقط با API پیکربندی‌شده اجرا می‌شود. حذف Deal در Didar انجام نمی‌شود، زیرا API حذفِ تأییدشده در کد وجود ندارد؛ حذف یا trash محلی فقط ثبت رویداد/diagnostic می‌شود.
